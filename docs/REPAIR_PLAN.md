# Atrium 完整启动器修复计划（2026-10-06）

基线：768f1fcd4bad28a0fc6582ddf1f5b4aec2ae4cb2。
用户已确认完整启动器定位、API 33 起、Pixel Watch 3 为主要验收设备。

## 复核结论

- 注册 MAIN/HOME/DEFAULT，同时保留 MAIN/LAUNCHER。是否能取得 Home 角色由设备决定。
- 主 Activity 复用；重复 Home 请求回到抽屉；引导未完成时保留引导。
- Home 会话根页面不退出；普通应用入口根页面允许返回退出。
- 实体表冠/电源键行为不假定由第三方接管，必须 Pixel Watch 3 实测。
- 应用操作纳入导航；隐藏管理有恢复入口；卸载后保留用户偏好。
- 所有 PackageManager 查询和图标读取移到后台；包变化和恢复前台均刷新。
- 引导保存完成才导航；写入失败反馈；不吞协程取消。
- 列表变形配对布局高度和视觉变换；图标网格的整行变换避免双重缩放。
- 系统输入采用 Wear RemoteInput；输入取消不清空原关键词。
- 性能选择使用 Wear M3 RadioButton；减弱动态仍按 SPEC 使用 standard 动效。
- Tile 保留打开抽屉功能，不扩展收藏捷径；WFF/seed 维持明确标注的预留能力。

## 执行顺序

1. 目录后台刷新、失效应用启动保护和图标。
2. Home/角色/导航、引导写入顺序、隐藏恢复。
3. 抽屉识别、系统输入、设置单选、完整变形与语义。
4. 更新文案、SPEC/README/验收说明。
5. 源码检查、构建和测试尝试；记录验证结果，提交并推送仓库（用户已取消打包）。

## 验收

- 安装/卸载/禁用目标应用后返回，目录更新；残留条目点击不崩溃。
- 隐藏应用可恢复；置顶和收藏有可见状态及读屏状态。
- 完成引导后重启不再显示；失败不提前导航。
- Home 重复进入不新增 Activity；从子页面回到抽屉；根返回不销毁 Home。
- 普通入口仍支持退出；角色取消/授权/外部更改后状态可刷新。
- 小/大圆屏、方屏、放大字体、触控48dp、读屏及旋转输入需设备验收。
- Gradle 构建、单元测试、Lint 和依赖禁用检查；阻断必须明确报告。
